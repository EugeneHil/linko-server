# linko-server

Signaling and messaging server of **Linko**, a private 1:1 messenger with audio/video calls and file transfer. C++17; runs on Windows (a small VPS) and macOS (development). Uses `linko-core` for the protocol and the call state machine.

Design: `linko-apple/docs/superpowers/specs/2026-10-25-linko-design.md` (in the `linko-apple` repository).
